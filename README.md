# Blobsquatch ($BLOBSQUATCH)

A meme coin on NEAR. Blobsquatch is a guy in a cheap Bigfoot costume, faking sightings with his buddy Barry. You had to be NEAR.

- `index.html` is the website (static, no build step).
- `art/locked/` holds the locked character art.
- `docs/` holds the brief, character bible, site spec and plans. Start with `CLAUDE.md`.
- `site/versions/` keeps earlier site versions for reference.

$BLOBSQUATCH is a meme token for fun, with no intrinsic value and no expectation of financial return. Not affiliated with or endorsed by the NEAR Foundation.
